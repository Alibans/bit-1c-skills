# Стандарты разработки 1С — выжимка

Источник: система стандартов 1С на ИТС, https://its.1c.ru/db/v8std (открыта без авторизации). Полный текст стандарта
с номером NNN: `https://its.1c.ru/db/v8std/content/NNN/hdoc`. При сомнении открой полный текст: выжимка короче и
грубее оригинала.

Применять только к своему коду и только разделы, которые касаются задачи. Стандарт — не повод добавлять механизм
(правило «Просто» в SKILL.md важнее).

## События объекта и проведение
- [ ] Первая строка `ПередЗаписью`, `ПриЗаписи`, `ПередУдалением`, в том числе в подписках, —
      `Если ОбменДанными.Загрузка Тогда Возврат; КонецЕсли;` (std773). `ОбменДанными.Загрузка` не использовать для отключения проверок.
- [ ] `Отказ` присваивается только `Истина`, пользователю сообщается причина (std686).
- [ ] В проведении табличную часть читать одним запросом, `Записать()` у наборов не вызывать, кроме контроля
      остатков. Контроль остатков — только при оперативном проведении и по std661.
- [ ] Свою транзакцию не открывать внутри записи или проведения (std783).
- [ ] Измерение регистра остатков имеет смысл и в приходе, и в расходе. Регистр не читает реквизиты регистратора через точку (std477).

## Безопасность (std669, 770, 774, 542, 485, 740)
- [ ] `Выполнить`/`Вычислить` на сервере — только по std770, внешний код — по std669. Под Фреш запрещены совсем.
- [ ] Файлы на сервере — по std542; временные — `ПолучитьИмяВременногоФайла()` с удалением после использования.
- [ ] Привилегированный режим — только по std485. Пароли не хранить в открытом виде (std740).

## Оформление модулей (std453–456, 640, 647, 680)
- [ ] Структура модуля по std455: области `ОписаниеПеременных`, `ПрограммныйИнтерфейс`, `ОбработчикиСобытий*`,
      `СлужебныеПроцедурыИФункции`, `Инициализация`. Пустых областей нет.
- [ ] Модуль объекта обёрнут в `#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда …
      #Иначе ВызватьИсключение НСтр("ru = 'Недопустимый вызов объекта на клиенте.'"); #КонецЕсли`, модуль менеджера — без `#Иначе` (std680).
- [ ] Экспортные методы описаны комментарием: назначение, `Параметры:`, `Возвращаемое значение:` (std453).
- [ ] Тексты на русском, без «ё», без неразрывных пробелов и «длинных» минусов (std456).
- [ ] Имена в ВерблюжьейНотации, осмысленные, без сокращений (std454, std647). У каждого события свой обработчик.
- [ ] Перенос длинных выражений по std444. Строки для пользователя — в `НСтр("ru = '…'")` (std761), подстановка —
      `СтрШаблон` или `СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку`.

## Конструкции языка (std439–499, 783, 648)
- [ ] Исключения не перехватывать без необходимости (std499). Перехватил — журнал регистрации с
      `ОбработкаОшибок.ПодробноеПредставлениеОшибки` (std498). Текст ошибки пользователю — как есть, не разбирать его.
- [ ] Транзакции (std783): `НачатьТранзакцию()` перед `Попытка`, в `Исключение` первым — `ОтменитьТранзакцию()`,
      потом журнал, потом `ВызватьИсключение`. Начало и конец — в одном методе. Не вокруг единственной записи объекта.
- [ ] Ответственное чтение (std648): данные, прочитанные для последующей записи, — под управляемой блокировкой
      `БлокировкаДанных` внутри транзакции (std460). Редактируемые пользователем объекты — `ЗаблокироватьДанныеДляРедактирования` (std490).
- [ ] Не `Сообщить()` (std418): `ОбщегоНазначения.СообщитьПользователю` / `СообщениеПользователю`.
- [ ] Отдельные реквизиты — `ОбщегоНазначения.ЗначениеРеквизитаОбъекта(ов)`, не `Ссылка.Реквизит` и не `ПолучитьОбъект()` (std496).

## Запросы (std412–437, 652–658, 729, 777)
- [ ] Не выполнять запросы в цикле (std436): собрать ссылки, один запрос, временные таблицы (std777).
- [ ] В `ГДЕ` без `ИЛИ` по разным полям, условия по индексу (std658, std652). Отборы виртуальных таблиц — в параметрах (std657).
- [ ] Поля составного типа — через `ВЫРАЗИТЬ` (std654). Не соединять с вложенными запросами и виртуальными таблицами (std655, std656).
- [ ] Оформление текста по std437, псевдонимы у всех полей и источников (std758). `УПОРЯДОЧИТЬ ПО`, если важен порядок;
      `ПЕРВЫЕ` без порядка даёт случайную запись (std412).
- [ ] Пустой результат — `Результат.Пустой()` (std438). `РАЗРЕШЕННЫЕ` — по std415 (под Фреш — в каждом запросе к таблицам).

## Клиент-сервер и формы (std487, 629, 636, 703, 404, 409, 630)
- [ ] Один серверный вызов на действие пользователя (std487). `&НаСервереБезКонтекста`, где контекст формы не нужен (std636).
- [ ] Нет модальных окон и синхронных вызовов: `ПоказатьВопрос`, `ПоказатьПредупреждение`, `ОписаниеОповещения` (std703).
- [ ] `РеквизитФормыВЗначение` — только когда нужен объект (std409). Логика — в модуле объекта или менеджера, не в форме (std486, std630).
- [ ] Форма в стиле конфигурации (std722, std620): командная панель сверху, основная команда — кнопка по умолчанию.
- [ ] Сообщения пользователю — безличные, информативные (std585, std598).

## Метаданные (std474, 478, 550, 432, 728)
- [ ] Имя, синоним и комментарий заполнены (std474). Строки ограниченной длины (std432). Составной тип — только когда без него никак (std728).
- [ ] Права на новые объекты — в ролях (std532, std689).

## Дополнительная обработка или отчёт (БСП «Дополнительные отчеты и обработки»)
- [ ] `СведенияОВнешнейОбработке()` в модуле объекта: вид, версия, команды, `Информация`, `БезопасныйРежим = Истина`.
- [ ] Встроенная справка и кнопка «Справка» на форме.
- [ ] Не обращаться к обработке по её имени: при подключении через БСП оно другое. Полное имя —
      `РеквизитФормыВЗначение("Объект").Метаданные().ПолноеИмя()`.
- [ ] Операции от 10 секунд — через длительные операции БСП (std642), сигнатуры сверять с версией БСП базы.
