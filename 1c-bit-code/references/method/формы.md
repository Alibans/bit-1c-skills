# Модуль управляемой формы

Стандарты: std439, std455, std487, std492, std642, std741, std703.

## Директивы
- У каждой процедуры формы ровно одна директива: `&НаКлиенте`, `&НаСервере` или `&НаСервереБезКонтекста`. Если контекст формы не нужен, используем `&НаСервереБезКонтекста`.
- В общем модуле `КлиентСервер` нельзя ветвиться через `#Если Сервер`/`#Если Клиент`: контекст там определяется ненадёжно. Логику раскладывают по модулям `…Клиент` и `…Сервер`, общую часть оставляют в `КлиентСервер`.
- Обработчики событий объекта (`ПередЗаписью` и др.) и обработчики формы (`ПередЗаписьюНаСервере` и др.) — разные места. `ПередЗаписьюНаСервере` выполняется **до** транзакции записи, `ПриЗаписиНаСервере` — внутри неё. Правило, которое должно работать при любой записи объекта, кладут в модуль объекта: форма срабатывает только при интерактивной записи.

## Серверные вызовы (std487)
- Одно действие пользователя — не больше одного серверного вызова из кода конфигурации. Если их больше, нужна названная причина.
- Параметры серверной процедуры, которую вызывают с клиента, передаются через `Знач`.
- Если операция длится от ~10 секунд, её переносят в фоновое задание (длительные операции БСП, std642). Синхронный вызов в таком случае не растягивают.
- Модальные окна не используют: `ПоказатьВопрос`, `ПоказатьПредупреждение`, `ОписаниеОповещения` (std703).

## Параметры формы (std741)
- Параметры объявляют на закладке «Параметры» формы. Тогда `ПриСозданииНаСервере` читает `Параметры.Имя` напрямую, а состав параметров виден без чтения кода. `Параметры.Свойство("Имя", …)` говорит о том, что параметр не объявлен.
- Форму, которая требует параметров и открывается только из кода, не делают основной и не показывают в «Все функции». Если она всё-таки основная, `ПриСозданииНаСервере` проверяет параметры и при их отсутствии вызывает исключение с понятным текстом.

## Прочее
- Обработчики, которые назначаются из кода через `УстановитьДействие`, называют с префиксом `Подключаемый_` (std492). Иначе проверка «неиспользуемые процедуры» примет их за мёртвый код.
- Обработчик события формы не вызывают из кода. Тело выносят в отдельную процедуру и вызывают её из обоих мест.
- Логику держат в модуле объекта или менеджера, в форме — только интерфейс (std486, std630).
