# В какой модуль положить код

Стандарты: std486, std469, std679, std724, std725, std746, std556.

## Модуль объекта, модуль менеджера или общий модуль (std486)
- **Модуль объекта** — для кода, который работает с конкретным экземпляром (`ЭтотОбъект`), в том числе до его записи: обработчики событий, заполнение. Если его экспортную процедуру вызывают снаружи, вызывающему придётся сделать `ПолучитьОбъект()`, а это чтение всего объекта с табличными частями.
- **Модуль менеджера** — для кода, которому экземпляр не нужен: работа со множеством объектов, печать по ссылке, движения по ссылке, обновление данных этого вида объектов. Получать здесь объект через `ПолучитьОбъект()`, чтобы обойти правило, нельзя.
- **Общий модуль** — для кода, который нельзя отнести ровно к одному объекту метаданных. Общий модуль собирает код одной подсистемы или одного назначения. Заводить его стоит, когда у кода появился второй потребитель, а не заранее.

## Четыре вида общих модулей (std469)
| Вид | Флаги | Окончание имени |
|---|---|---|
| Серверный | Сервер, Внешнее соединение, Клиент (обычное прил.) | нет (или `Сервер` при совпадении имён) |
| Серверный для вызова с клиента | Сервер + Вызов сервера | `ВызовСервера` |
| Клиентский | Клиент (упр.), Клиент (обычное прил.) | `Клиент` (или `Глобальный`) |
| Клиент-серверный | Клиент + Сервер + Внешнее соединение | `КлиентСервер` |

Есть и другие окончания: `ПолныеПрава` (привилегированный модуль) и `ПовтИсп` (повторное использование). В имени не должно быть пустых слов вроде «Процедуры», «Функции» или «Модуль».

## Флаг «Вызов сервера» — это граница безопасности (std679)
- Флаг не ставят «чтобы скомпилировалось». В модуль с этим флагом кладут только то, что действительно вызывается с клиента.
- Такая функция возвращает готовый результат и не отдаёт исходные данные, на которые у пользователя может не быть прав. Особенно внимательно — если внутри привилегированный режим.
- Объекты (`СправочникОбъект`, `ДокументОбъект`) создаются и читаются только на сервере.

## Кэш, модули ПовтИсп (std724, std725)
- Кэшировать стоит то, что дорого получить и часто читают: данные из базы, из внешних источников, тяжёлые вычисления. Константу, строку или предопределённый элемент не кэшируют.
- Значение живёт в кэше не дольше 20 минут после вычисления и 6 минут после последнего обращения. Если его редко читают повторно, кэш только занимает память.
- Добавлять кэш нужно с причиной: что он читает и как часто это читают повторно.

## Обработчики представления в модуле менеджера (std746)
`ОбработкаПолученияПредставления` и `ОбработкаПолученияПолейПредставления` вызываются при каждом показе ссылки. Запросы, `ПолучитьОбъект()` и обращения к реквизитам ссылки через точку внутри них запрещены.

## Первый запуск и обновление версии (std556)
- Обработчики обновления создают данные только после проверки, что таких ещё нет. Безусловное создание в РИБ размножит данные по всем узлам.
- Обязательное начальное заполнение отделять от необязательного.
