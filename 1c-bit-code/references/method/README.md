# Методика: какое решение выбрать

Стандарты ([../стандарты.md](../стандарты.md)) отвечают на вопрос «как правильно написать». Методика — «какое решение
выбрать»: где разместить код, какой обработчик взять, какой объект метаданных создать, как провести документ и что
заблокировать. Правила опираются на стандарты (stdNNN, полный текст — `https://its.1c.ru/db/v8std/content/NNN/hdoc`).

Источник: методички плагина Unica (github.com/IngvarConsulting/unica, `plugins/unica/references/platform`,
лицензия LGPL-3.0), сокращены, переведены и сверены с полными текстами стандартов.

## Главное правило: не усложнять
Методика описывает, как решить задачу, когда она возникла. Это не список механизмов, которые положено добавить:
- Минимальное решение, которое закрывает задачу. Ничего «на будущее» и ничего «по стандарту положено».
- Механизм — только при названной причине. Нельзя сказать причину одной фразой — механизм не нужен.
- Правило, которое не относится к задаче, не применяем. Методика — не повод переделывать соседний работающий код.
- Заимствованный код переносим как есть (раздел «Заимствованный код» в SKILL.md).
