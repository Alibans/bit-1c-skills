# Скриншоты для описаний и клиентских карточек

Скриншоты в документах — живые формы расширения на **демоданных**: так клиент видит, как это будет у него.
Инструменты — в `assets/screenshots`. Принцип: данные готовятся кодом, формы открываются кодом в 1С,
окно 1С снимается через PrintWindow по сигналу «шаг готов». Мышь и клавиатура не нужны, окна пользователя
не трогаются.

## Правила
- **Только демобаза.** Ни рабочую базу клиента, ни её копию не снимать — в материалы попадут реальные данные.
  Если сомневаетесь, что за база, — посмотрите организации и контрагентов запросом и спросите.
- **Документы для скриншотов можно создавать** в демобазе, если пользователь разрешил. Период — тот, где в демобазе
  есть движения (в демо «Бухгалтерии для Казахстана» это обычно 2017 год), иначе формы будут пустыми.
- **Снимать только окно 1С**, никогда весь экран: у пользователя открыты другие программы.
- **Не завершать чужой сеанс.** Открывалка в конце закрывает только формы, которые открыла сама.
- Перед вставкой — обрезать снимок до сути: без заголовка окна, левого меню, пустых областей, служебных строк
  внизу окна (System.Drawing, см. пример в конце).

## Какой способ выбрать
| Ситуация | Скрипт |
|---|---|
| В базе уже открыт сеанс с MCP Toolkit (обычно так), или лицензия пускает одного клиента («версия для разработчиков») | `shoot-session.ps1` — снимает в этом сеансе |
| Можно открыть второй сеанс | `shoot.ps1` — запускает свой тонкий клиент и закрывает его после съёмки |

Признак лимита лицензии: `1cv8c` сразу завершается с кодом 1, а запуск с `/Out <файл>` пишет «Превышено
ограничение лицензии для разработчиков на количество клиентов информационной базы».

## Порядок
1. **Подготовить данные** серверным кодом через Toolkit (`1c-toolkit`: `toolkit.ps1 -Action code -CodeFile …`):
   создать документы функциями самого расширения — так результат совпадает с тем, что увидит пользователь.
   Учтите, что в демобазе может стоять другая сборка расширения: если функции нет («Метод объекта не обнаружен»),
   повторите её логику из более простых экспортных функций.
2. **Описать сценарий** в модуле формы открывалки `assets/screenshots/src/БИТ_Скриншоты/Forms/Форма/Ext/Form/Module.bsl`:
   `Шаг1`, `Шаг2`… открывают формы с данными (`ПолучитьФорму` → заполнить `Объект` → `Открыть()`), после каждого шага —
   `Флажок(N)`. Готовые примеры: `acts` (форма обработки с результатами + созданный документ) и `esfcosts`
   (отчёт СКД, сформированный на сервере и показанный `ТабличныйДокумент.Показать()`). Модули конфигурации и
   расширения вызывать через `Вычислить("Модуль.Функция(П)")` — открывалка собирается на пустой базе, где их нет.
   Каталог флажков — `КаталогВременныхФайлов() + "bitshots"`, сценарий читается из `scenario.txt` там же.
3. **Собрать открывалку:** `powershell -File assets\screenshots\build-opener.ps1` (сборка идёт через ASCII-путь,
   кириллица в путях ломает пакетный Конфигуратор) → `shot.epf`.
4. **Снять** из папки проекта (там `.claude\.secrets\toolkit.json`):
   ```
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File <скилл>\assets\screenshots\shoot-session.ps1 -Scenario acts -Steps 2 -OutDir <папка>
   ```
   Скрипт подключает `shot.epf` в сеансе (`ВнешниеОбработки.Подключить`), открывает её форму на клиенте,
   ставит окну временный заголовок, чтобы найти именно этот сеанс среди окон 1С, снимает `step<N>.png` и
   возвращает заголовок. Окно сеанса должно быть развёрнуто (не свёрнуто).
5. **Обрезать** и положить в `img\` рядом с `description.json` / `card.js` расширения.
6. Сказать пользователю, что осталось в демобазе: созданные документы, открытые вкладки (окно
   `ТабличныйДокумент.Показать()` кодом не закрыть).

`capture-window.ps1 -ProcessId <pid>` — посмотреть, что сейчас в окне сеанса (если открывалка «зависла»).

## Обрезка
```powershell
Add-Type -AssemblyName System.Drawing
$i = [Drawing.Image]::FromFile("step1.png"); $r = New-Object Drawing.Rectangle 212, 76, 1700, 508
$b = New-Object Drawing.Bitmap $r.Width, $r.Height; $g = [Drawing.Graphics]::FromImage($b)
$g.DrawImage($i, (New-Object Drawing.Rectangle 0, 0, $r.Width, $r.Height), $r, [Drawing.GraphicsUnit]::Pixel)
$g.Dispose(); $i.Dispose(); $b.Save("form.png", [Drawing.Imaging.ImageFormat]::Png); $b.Dispose()
```
Для карточки клиента обычно нужен фрагмент поуже (таблица с результатом), иначе на странице он мелкий.
