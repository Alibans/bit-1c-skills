# Расширение сразу под 1С:Фреш

Расширение продаётся многим клиентам, часть из них работает в 1С:Фреш (1cfresh.kz). Там расширение исполняется
в **безопасном режиме**, под пользователями **без прав администратора**, через **веб-клиент**, и перед допуском
проходит **аудит кода**. Если писать сразу по этим правилам, одна и та же сборка работает и локально, и в сервисе.
Полные тексты требований сервиса — в скилле `1c-fresh` (если он установлен).

## Содержание
1. Запрещено в коде расширения
2. Интерфейс: без модальности и синхронных вызовов
3. Длительные операции (от 10 секунд)
4. Настройки без констант и без записи при старте
5. Данные, права, запросы
6. Перехваты типового кода и типовые макеты
7. Интернет и передача данных наружу
8. Регламентные задания
9. Чек-лист перед сдачей

## 1. Запрещено в коде расширения
- `Выполнить()`, `Вычислить()`;
- COM-объекты, внешние компоненты, запуск приложений ОС (сервер сервиса — Linux);
- работа с файлами, кроме временных: `ПолучитьИмяВременногоФайла()` и обязательное удаление после использования;
- `УстановитьПривилегированныйРежим(Истина)` — в безопасном режиме не действует, аудитор считает ошибкой;
- обращения в интернет (HTTPСоединение и т.п.) без подтверждения пользователя — см. раздел 7;
- универсальные инструменты, меняющие данные (групповая замена реквизитов, «перенумераторы», удаление помеченных):
  расширение решает одну конкретную задачу;
- модули с паролем или обфускацией;
- `ОбменДанными.Загрузка = Истина` и другое отключение штатных проверок;
- неиспользуемый код, формы, макеты (аудит требует минимализма).

Безопасный режим распространяется и на типовой код, вызванный из расширения (кроме привилегированных общих
модулей конфигурации). Значит, если расширение вызывает типовую функцию, которая ходит в интернет или на диск,
в сервисе она тоже не сработает.

## 2. Интерфейс
- Никаких `Вопрос()`, `Предупреждение()`, `ОткрытьФормуМодально()`, `ДиалогВыбора*.Выбрать()`, `ВвестиЗначение()`.
  Только асинхронные: `ПоказатьВопрос`, `ПоказатьПредупреждение`, `ОткрытьФорму(..., ОписаниеОповещения)`,
  `Диалог.Показать(ОписаниеОповещения)`.
- Всё должно работать в веб-клиенте без расширения работы с файлами.

```bsl
&НаКлиенте
Процедура ВыбратьЦвет(ИмяНастройки, ТекущийЦвет)
	Диалог = Новый ДиалогВыбораЦвета;
	Диалог.Цвет = ТекущийЦвет;
	Диалог.Показать(Новый ОписаниеОповещения("ВыбратьЦветЗавершение", ЭтотОбъект, ИмяНастройки));
КонецПроцедуры

&НаКлиенте
Процедура ВыбратьЦветЗавершение(ВыбранныйЦвет, ИмяНастройки) Экспорт
	Если ВыбранныйЦвет = Неопределено Тогда
		Возврат;
	КонецЕсли;
	СохранитьЦветНаСервере(ИмяНастройки, ВыбранныйЦвет);
КонецПроцедуры
```

## 3. Длительные операции
Всё, что на большой базе может идти 10 секунд и дольше (массовое создание документов, подбор по оборотам,
обращение к сервису), — только через длительные операции БСП. Иначе веб-сервер оборвёт вызов по таймауту.

```bsl
// Модуль с вызовом сервера (ВызовСервера = Истина)
Функция НачатьСоздание(МассивДокументов, ИдентификаторФормы) Экспорт
	ПараметрыВыполнения = ДлительныеОперации.ПараметрыВыполненияФункции(ИдентификаторФормы);
	ПараметрыВыполнения.НаименованиеФоновогоЗадания = НСтр("ru = 'БИТ: Создание документов'");
	Возврат ДлительныеОперации.ВыполнитьФункцию(ПараметрыВыполнения,
		"БИТ_Пример_Сервер.СоздатьДокументы", МассивДокументов);
КонецФункции

// Клиент
ДлительнаяОперация = БИТ_Пример_ВызовСервера.НачатьСоздание(Массив, Форма.УникальныйИдентификатор);
ПараметрыОжидания = ДлительныеОперацииКлиент.ПараметрыОжидания(Форма);
ПараметрыОжидания.ТекстСообщения = НСтр("ru = 'Создание документов...'");
ПараметрыОжидания.ВыводитьПрогрессВыполнения = Истина;
ДлительныеОперацииКлиент.ОжидатьЗавершение(ДлительнаяОперация,
	Новый ОписаниеОповещения("СозданиеЗавершение", ЭтотОбъект, Доп), ПараметрыОжидания);

// В фоновой функции прогресс — не чаще ~50 раз за операцию:
ДлительныеОперации.СообщитьПрогресс(Цел(Обработано * 100 / Всего),
	СтрШаблон(НСтр("ru = 'Обработано: %1 из %2'"), Обработано, Всего));
```
В завершении: `Результат = Неопределено` — пользователь отменил; `Результат.Статус = "Ошибка"` — показать
`Результат.КраткоеПредставлениеОшибки`; иначе данные — `ПолучитьИзВременногоХранилища(Результат.АдресРезультата)`.
Функция, выполняемая в фоне, должна **возвращать** результат, а не менять переданный параметр: форма получает копию.

## 4. Настройки
Константы — это расширение данных, их запись требует прав, а запись «при первом запуске» ломает вход пользователю
без прав. Простые настройки храните в хранилище общих настроек, пустая настройка = значение по умолчанию.

```bsl
Функция ЗначениеНастройки(ИмяНастройки, ПоУмолчанию) Экспорт
	Значение = ОбщегоНазначения.ХранилищеОбщихНастроекЗагрузить("БИТ_Пример", ИмяНастройки);
	Возврат ?(Значение = Неопределено, ПоУмолчанию, Значение);
КонецФункции

Процедура СохранитьНастройку(ИмяНастройки, Значение) Экспорт
	ОбщегоНазначения.ХранилищеОбщихНастроекСохранить("БИТ_Пример", ИмяНастройки, Значение);
КонецПроцедуры
```
Ничего не писать в `ПриНачалеРаботыСистемы` и других обработчиках запуска. На форме настроек — кнопка «По умолчанию».
Если без констант/реквизитов не обойтись (данные документа — например, новый реквизит счёта), это допустимо:
расширение будет «расширяющим данные», имена реквизитов — с префиксом расширения.

## 5. Данные, права, запросы
- `ВЫБРАТЬ РАЗРЕШЕННЫЕ` в каждом запросе пакета, который читает таблицы базы (первый ВЫБРАТЬ каждого запроса;
  вложенным запросам и второй части ОБЪЕДИНИТЬ не нужно).
- Перед добавлением колонки/поля, которые читают чужой регистр, проверить `ПравоДоступа("Чтение", Метаданные...)`.
- Код в обработчиках типовых форм (`&После("ПриСозданииНаСервере")`, `ПриПолученииДанныхНаСервере`) — в `Попытка`,
  ошибка пишется в журнал регистрации и **не** ломает типовую форму:
  `ЗаписьЖурналаРегистрации("БИТ.Пример", УровеньЖурналаРегистрации.Ошибка, , Ссылка, ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()))`.
  Пользователю — `КраткоеПредставлениеОшибки`, подробности — в журнал (не скрывать ошибки совсем).
- Элементы типовой формы искать через `Элементы.Найти("Имя")` и проверять `<> Неопределено`: после обновления
  конфигурации элемента может не быть.
- Запросы: без соединений с виртуальными таблицами в условиях `ИЛИ`, без обращения через точку к составным полям,
  отборы — в параметры виртуальных таблиц. Запрос в цикле по строкам — заменить одним запросом до цикла.
- Основная роль: `setForNewObjects=true` (права на свои объекты). В сервисе роль добавляют в профиль групп доступа —
  напишите это в инструкции по установке.

## 6. Перехваты типового кода и типовые макеты
- `&ИзменениеИКонтроль` всей типовой функции — крайняя мера: весь её код (включая типовой привилегированный режим,
  интернет, Kaspi QR и т.п.) начинает выполняться как код расширения в безопасном режиме, а при обновлении
  конфигурации перехват перестаёт применяться. Предпочтительно `&После`/`&Перед` и доработка готового результата.
- Не заимствуйте типовой макет печатной формы, чтобы дописать в него область: заимствованный макет заменяет
  типовой целиком, обновления макета от 1С до клиента не дойдут, а пользовательский макет («Макеты печатных форм»)
  не будет содержать вашей области. Своя область — в **своём** макете (`ПолучитьМакет("БИТ_Пример_...")`).
- Собственная копия типовой печати — только если иначе нельзя; из копии убрать привилегированный режим и
  интернет-вызовы, остальное не переписывать.

## 7. Интернет и передача данных
Любая передача данных клиента за пределы базы — только после явного согласия пользователя, с указанием, что и куда
уходит (`ПоказатьВопрос` перед операцией; ответ можно запомнить в настройке). Если адреса известны заранее —
запрос разрешений в программном интерфейсе расширения. Это касается и вызовов типовых сервисов (КГД и т.п.).

## 8. Регламентные задания
Регламентное задание расширения в разделённой базе сервиса само не выполняется. Если оно нужно:
`Использование = Ложь` по умолчанию (включает администратор локальной базы), первой строкой обработчика —
`ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания(Метаданные.РегламентныеЗадания.<Имя>)`, задание с
передачей данных наружу без подтверждения не запускать; для сервиса — ручной запуск из формы с подтверждением.
Расписание — разумное (раз в сутки, а не каждые 10 минут).

## 9. Чек-лист перед сдачей
Составьте таблицу «требование → как выполнено» и отдельно «что не проверено»:

| Требование | Как проверить |
|---|---|
| Нет запрещённого (раздел 1) | поиск по модулям: `Выполнить(`, `Вычислить(`, `COMОбъект`, `ПодключитьВнешнююКомпоненту`, `УстановитьПривилегированныйРежим`, `HTTPСоединение`, `Новый Файл`, `ЗаписьТекста` |
| Нет модальности | поиск: `Вопрос(`, `Предупреждение(`, `ОткрытьФормуМодально`, `.Выбрать()`, `ВвестиЗначение(` |
| Длительные операции | всё массовое — через `ДлительныеОперации` |
| РАЗРЕШЕННЫЕ | каждый запрос к таблицам базы |
| Не ломает типовые формы без прав | Попытка + журнал, `Элементы.Найти`, `ПравоДоступа` |
| Уникальное имя и версия | `БИТ_<Имя>`, версия поднята |
| Справка | у каждой своей формы есть «?», страница «Возможности расширения» заполнена |
| Модули без пароля | — |
| Проверка платформой | загрузка в тестовую базу, `/CheckCanApplyConfigurationExtensions`, `/CheckConfig -ThinClient -WebClient -Server -Extension` |

Обычно не проверено и это надо честно написать: клиент-серверная база с веб-публикацией, работа под пользователем
без «Администратора системы», сам аудит сервиса.
